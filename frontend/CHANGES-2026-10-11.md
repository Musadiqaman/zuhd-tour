# Zuhd Tours — update of 11 October 2026

## What changed

- Rebuilt the homepage in the existing navy/gold brand, led by desert safaris.
- Added an accessible four-slide hero with arrows, slide selectors, pause/resume, touch swipes, and reduced-motion support. Automatic rotation pauses during interaction or when the tab is hidden; reserved text space prevents the section jumping between slides.
- All eight reference desert packages now have prices, detail pages, inclusions, exclusions, pickup information, galleries and approximate itineraries.
- City Tours now features Dubai, Abu Dhabi, Sharjah and Ras Al Khaimah, with full package pages and the reference prices.
- The menu now says **Transfer** instead of **Airport**, opening the complete airport, hotel and private/city transfer page.
- The **Combo** menu item is replaced by **FAQs**: a dedicated page with topic navigation, search and accessible expandable answers.
- Tour, transfer and contact forms prepare a WhatsApp message containing the visitor’s details. They do not silently discard form fields or claim a confirmed booking.
- Replaced the reference experience imagery with local, visually equivalent WebP files. 65 unique source images occupy about 9.5 MiB after deduplication/optimisation; there are no reference-site image hotlinks in the new pages.
- Updated page titles, descriptions, H1/H2 structure, image alt text, related-tour links, breadcrumbs and relevant service/FAQ structured data.

## Content decisions

Reference: https://wwwzuhdtourscom.netlify.app — inspected 11 October 2026. Machine-readable price provenance is in `REFERENCE-PRICE-INVENTORY.json`.

- The reference repeats a generic “pickup included” message on the standalone quad/buggy pages, but its package exclusions explicitly make hotel transport an add-on. The updated site follows those package-specific exclusions.
- The reference BBQ page has both 5 and 6 hours. The package card, booking sidebar and 4–9 PM itinerary agree on about 5 hours; that is used consistently.
- Reference review cards explicitly identify themselves as placeholders. No placeholder testimonials or unverified review scores were imported.
- The reference contact details and payment integration are placeholders. Existing Zuhd Tours domain, phones and email were kept; no fake contacts or checkout were imported.
- Reference cancellation/legal pages call themselves demo templates. FAQs direct guests to get the applicable terms in their confirmation rather than invent a binding cancellation policy.
- Starting fares do not invent child/infant rates, private-vehicle prices, intercity per-route fares or paid attraction admission. These are confirmed by the team.
- Earlier custom tours and their URLs remain available. The existing Global Village listing and its AED 75 value were retained because the reference does not provide a replacement price.
- Illustrative reference imagery is not described as independently verified customer photography.

## Routes and existing setup

This is the same Vite/React project, not a framework migration. The existing prerender and build configuration are retained. New pages are registered in the existing route list so builds include them. The old airport URL redirects to `/transfers`; `/faq` redirects to `/faqs`. The old Combo URL remains accessible for existing links, but it is not in the menu.

No account, DNS, Search Console or live hosting changes were made.

## Use the update

1. Extract `zuhd.zip`.
2. Copy the contents of `zuhd/frontend` into your current frontend folder, replacing the old files.
3. In that frontend folder, run `npm ci`, then `npm run build`.
4. Commit and push the updated frontend to your existing GitHub/Vercel project.

Suggested commit message: `Update safari packages, city tours, transfers, FAQs and homepage`

Future content edits: `src/data/experienceCatalog.js` contains package facts/prices; `src/data/faqData.js` contains the FAQ topics; `src/data/siteConfig.js` contains your existing business contact details.
