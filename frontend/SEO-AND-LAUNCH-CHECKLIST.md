# Zuhd Tours — SEO & Launch Checklist

## On-page SEO
- One unique title and meta description per indexable route.
- One clear H1 per page; H2/H3 hierarchy follows page sections.
- Clean keyword-focused URLs such as `/desert-safari-dubai-tours` and `/tours/evening-desert-safari-dubai`.
- Descriptive image alt text; compress WebP/AVIF images and use responsive sizes.
- Internal links between tours, destination guides, blog articles and booking pages.
- Canonical URLs on every indexable page.
- Open Graph/Twitter metadata for sharing.

## Technical SEO
- XML sitemap is included and lists core pages, tours and blog routes.
- robots.txt points crawlers to the sitemap.
- HTTPS must be enabled on the real production domain.
- Configure a custom 404 and redirect old URLs if this replaces another site.
- Keep Core Web Vitals strong: optimized images, limited third-party scripts, lazy loading below the fold.
- Add Organization/TravelAgency, TouristTrip/TouristAttraction and FAQ structured data where the visible page content supports it.
- Submit the production sitemap in Google Search Console and Bing Webmaster Tools.

## Local SEO
- Create and fully verify the Google Business Profile with the real business details.
- Keep name, address, phone and opening hours consistent across the website and business profiles.
- Add Dubai service areas and genuine tour/office information.
- Collect genuine customer reviews; do not publish fabricated reviews.

## Content SEO
Build useful pages around real search intent, for example:
- Dubai Desert Safari Guide
- Evening Desert Safari Dubai
- Morning Desert Safari Dubai
- Overnight Desert Safari Dubai
- Private Desert Safari Dubai
- Dubai City Tour
- Old Dubai & Al Fahidi Guide
- Dubai Creek & Al Seef Guide
- Palm Jumeirah Tour
- Dubai Marina Tour
- Dubai Airport Transfer
- Dubai Dhow Cruise

Each article should answer the query fully, use original photography where possible, link to relevant tours, and include an obvious booking/contact CTA.

## Conversion / trust
- Replace placeholder phone, WhatsApp, email and domain with the client's real details.
- Add real licensing/insurance claims only if documented.
- Add real cancellation/refund policy, payment methods, pickup coverage and terms.
- Add genuine testimonials and review-source links.
- Add a clear WhatsApp CTA and a short booking form.

## Analytics
- Google Analytics 4.
- Google Search Console.
- Track tour-view, WhatsApp-click, phone-click, booking-form-submit and completed booking events.
- Use UTM parameters for paid/social campaigns.

## Performance
- Serve local optimized images rather than large remote originals in production.
- Lazy-load below-the-fold media.
- Preload only the critical hero image/font.
- Keep JavaScript dependencies small.
- Test mobile first and run Lighthouse/PageSpeed before launch.
